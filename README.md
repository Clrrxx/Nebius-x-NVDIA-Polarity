# Polarity

An AI lab partner that catches wiring mistakes before the circuit fails, and shows the TA where the class is stuck.

Built for the Nebius x NVIDIA Global AI Hackathon (Physical AI track). Full documentation lands with the
final build; for now, Phase 0 verifies Nebius Token Factory access:

```bash
python -m polarity verify          # or scripts/verify_mac.sh / scripts\verify_windows.bat
```
